# 알티넬 텍스트 편집

`아카데미-알티넬-V10-텍스트-편집용-확장.xlsm`의 기존 시트와 추가된 **기타 화면 문구** 시트에서 노란색 셀을 수정합니다. ID, 행 순서, 시트명은 유지하세요. 매크로를 실행할 필요는 없습니다.

추가 시트에는 스포일러 안내, 정체 공개·숨김 버튼, 봉인 문구, 메뉴, 상세창, 알림, 검색 설명, 접근성 설명과 채팅 URL이 있습니다. 동적 문구는 `ui:`로 시작하는 ID입니다. 같은 의미의 문구라도 적용 위치가 다르면 별도 행일 수 있습니다.

엑셀만 저장해도 사이트가 자동 갱신되지는 않습니다. 수정본을 채팅에 업로드하거나, Python의 `openpyxl`과 Node.js가 설치된 환경에서 저장소 루트에서 다음 명령을 실행합니다.

```sh
python tools/sync_text.py editor/아카데미-알티넬-V10-텍스트-편집용-확장.xlsm
```

도구는 인물 ID로 연결된 이미지와 CSS를 보존하고, 텍스트를 HTML에 맞게 이스케이프합니다. 변경한 HTML을 확인한 뒤 `main`에 반영하면 설정된 GitHub Pages 배포가 시작됩니다.
