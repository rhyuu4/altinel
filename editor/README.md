# 알티넬 텍스트 편집

`아카데미-알티넬-V10-텍스트-편집용-27명-임시추가.xlsm`의 기존 시트와 추가된 **기타 화면 문구** 시트에서 노란색 셀을 수정합니다. ID, 행 순서, 시트명은 유지하세요. 매크로를 실행할 필요는 없습니다.

추가 시트에는 스포일러 안내, 정체 공개·숨김 버튼, 봉인 문구, 메뉴, 상세창, 알림, 검색 설명, 접근성 설명과 채팅 URL이 있습니다. 동적 문구는 `ui:`로 시작하는 ID입니다. 같은 의미의 문구라도 적용 위치가 다르면 별도 행일 수 있습니다.

엑셀만 저장해도 사이트가 자동 갱신되지는 않습니다. 수정본을 채팅에 업로드하거나, Python의 `openpyxl`과 Node.js가 설치된 환경에서 저장소 루트에서 다음 명령을 실행합니다.

```sh
python tools/sync_text.py editor/아카데미-알티넬-V10-텍스트-편집용-27명-임시추가.xlsm
```

도구는 인물 ID로 연결된 이미지와 CSS를 보존하고, 텍스트를 HTML에 맞게 이스케이프합니다. 변경한 HTML을 확인한 뒤 `main`에 반영하면 설정된 GitHub Pages 배포가 시작됩니다.

현재 명부는 27명(나스카 09, 카시아 27)이며, 보스를 포함한 전투 능력은 31명입니다.

사이트 이미지는 원래 해상도를 유지한 품질 92의 손실 WebP입니다. 향후 PNG/JPEG 이미지를 적용한 뒤 아래 명령으로 변환할 수 있습니다. 원본 HTML과 이미지, 변환 보고서는 지정한 백업 디렉터리에 남습니다. 기존 이미지와 CSS의 모양·배치는 변경하지 않습니다.

```sh
python tools/optimize_images.py --backup-dir /workspace/altinel-originals/manual-update --quality 92
```

지도는 `assets/maps.js`의 SVG 지형으로 구성됩니다. 엑셀의 **지도 지역** 시트에서 지역 이름·분류·설명을 수정하면 같은 반영 명령으로 지도 설명도 갱신됩니다. **대륙과 국가** 시트는 기존 자료 보관용이며 현재 지도에는 카드로 표시되지 않습니다. 지형·좌표와 지도 전환 동작은 코드에서 관리합니다.

세계지도 선택 항목은 6개 국가와 운석호·플로렌 옛터입니다. 도시·군항 등은 국가 설명에 통합되어 있습니다. 중앙 알티넬 모형은 교내 지도 전환 버튼입니다. 교내 지도는 7개 구획을 유지합니다. 이름표뿐 아니라 지형·건물 면 자체를 클릭하거나 키보드 Enter/Space로 선택할 수 있습니다.



현재 세계지도는 `assets/world-parchment.webp`를 사용하며 별도 지형 도형은 덧그리지 않습니다. `WORLD_LANDS`는 해안선을 따른 투명 클릭 구획이고, 오페라 선택 영역은 지도에 그려진 정글 전역을 포함하며 숲 영역에서는 크로이츠보다 우선합니다. 운석호는 그림의 넓은 수면에 맞춘 별도 클릭 경로를 갖습니다. 두 지도 모두 이름표 이미지는 사용하지 않고 최상단 글씨 레이어만 사용합니다. 세계지도는 짙은 갈색 글씨·황토색 테두리, 교내 지도는 현대적인 산세리프·남색 글씨·흰 테두리입니다.

세계지도 글씨는 이전 크기의 1/1.2입니다. 플로렌 옛터는 그림의 폐허 위치에 맞춘 `FLOREN_FOOTPRINT`를 기준으로 중심 (510,354)에서 가로·세로 각각 1.3배 확대해 클릭 여유를 줍니다.

교내 지도는 수정된 원본(1369×989)을 `assets/campus-illustrated.webp`로 최적화해 사용합니다. `CAMPUS_TARGETS`의 원본 픽셀 좌표 다각형으로 구획을 잡으며, 앞쪽 성문·소마탑·기숙사가 본관보다 선택 우선순위가 높습니다. 산호 군락은 오른쪽 동굴 군집과 연결 다리, 야외 훈련장은 말뚝으로 둘러싸인 수면에 한정합니다. 외해·배·먼 전경의 산호초는 배경입니다.

교내 지도의 영어 표기는 **지도 지역 F열**에서 수정합니다. 한글의 45% 크기로 아래에 표시하며 색·테두리·서체 양식은 같습니다. 산호 군락·야외 훈련장·성문은 다른 교내 장소의 70% 크기입니다. 영어도 각 장소의 축소된 한글을 기준으로 비율을 유지합니다. 세계지도에도 영어 부제를 표시하며, 양피지에 어울리는 세리프 서체를 사용합니다.

교내 영어는 최초 30%에서 50% 확대해 한글의 45%로 표시합니다. 세계지도는 직전 글씨의 80%, 운석호·플로렌 옛터는 추가 90%를 적용한 72%입니다. 위치와 클릭 범위는 유지합니다.
